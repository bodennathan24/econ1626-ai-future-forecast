# AI and the Future of Australian Real Estate by 2030

This repository contains an interactive web essay for Assessment 3: Interactive Web Essay.

The project forecasts how artificial intelligence may reshape Australia's real estate industry by 2030. It focuses on how AI could affect property search, valuations, real estate agents, buyers, renters, investors, and regulators.

## Project Focus

The essay argues that AI will improve productivity and reduce some transaction costs in real estate, but may also increase information inequality, privacy risks, and market power if not governed carefully.

## Files

- `forecast.html` — the main interactive web essay
- `README.md` — project overview and navigation

## Interactive Features Planned

The web essay will include:

- Scenario buttons for baseline, upside, and downside futures
- A simple visual showing AI impact across real estate tasks
- Policy and governance implications for Australia’s real estate industry
